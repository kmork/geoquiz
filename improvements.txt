 This is a site for learning geography through gamification. Could you give me suggestions for new games or other improvements for such a purpose?

  ---
  New Game Ideas

  1. Border Draw

  Given two neighboring countries, draw/trace the approximate border between them on a blank map. Score based on accuracy. This builds deep spatial memory of country shapes and adjacency.

  2. Population Order / Area Order

  Given 4–6 countries, drag them into the correct order by population (or area). A ranking/sorting mechanic you don't currently have. Builds intuition for scale.

  3. Continent Sprint

  Name all countries in a continent as fast as possible (typed). A pure speed/recall challenge — like Sporcle-style quizzes. Simple to build with your existing data and autocomplete component.

  ---
  Improvements to Existing Features

  9. Spaced Repetition in Study Mode

  Track which countries/capitals the user gets wrong across games and surface those more frequently. This is the single highest-impact learning improvement — it turns random quizzing into targeted practice.

  10. Progress Dashboard

  A page showing overall mastery: which continents/countries the user knows well vs. struggles with, games completed, streaks, historical scores. Motivates continued play and shows gaps.

  14. Sound Effects / Audio Cues

  Correct/incorrect sounds, streak sounds, completion fanfare. Audio feedback significantly improves engagement and learning reinforcement.
